# MarkTask

Gestion de tâches personnelle — PWA hébergée sur GitHub Pages, données synchronisées via Firebase.

Application en ligne : **https://edouardsan.github.io/MarkTask/**

- [plan.md](plan.md) — le plan de réalisation par blocs.
- [GUIDE-UTILISATEUR.md](GUIDE-UTILISATEUR.md) — le guide à remettre à l'utilisateur.

Note de maintenance : à chaque déploiement, incrémenter le « version N » du menu ☰
dans `index.html` — c'est le repère qui permet de vérifier quelle version tourne
sur un appareil.
